# Экзамен АЭС\n\n## 1. Деплой через GitHub Pages (Рекомендуемый)\n1. Загрузите файлы репозитория в ветку `main`.\n2. Откройте Settings -> Pages -> Deploy from branch (ветка `main`, папка `/ (root)`).\n3. Полученную ссылку вставьте в поле 'URL приложения' в кабинете разработчика VK.\n\n## 2. Деплой на VK Hosting через консоль\n1. Укажите ваш числовой `app_id` в файле `vk-hosting-config.json`.\n2. Выполните в терминале команду:\n   `npx @vkontakte/vk-miniapps-deploy`\n
